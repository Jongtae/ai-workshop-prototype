# OFFSITE · AI Workshop

7명의 AI에게 워크숍을 맡기고, 서로의 생각이 바뀐 과정과 돌아온 결과를 살펴보는 공개 정적 프로토타입입니다.

- 남산·국립중앙박물관 워크숍의 요약 기록 전환
- 단계별 재생·일시정지·탐색과 전체 기록 보기
- 7개 AI 역할별 기여 보기
- 바뀐 결정과 귀환 보고, JSON 다운로드
- 다음 의뢰 초안을 브라우저에만 저장

## 경계

이 사이트는 **실제로 진행한 subagent 워크숍을 정리한 기록 재생**입니다. 원시 대화 로그가 아니며, 화면에서 새로운 AI를 실행하지 않습니다. 장소 방문과 관광은 모의 활동입니다. 7개 AI 역할의 GO 권고는 인간 고객 조사나 시장성·정확성 검증이 아닙니다.

외부 AI API, 계정, 분석 추적, 서버, 외부 폰트가 없습니다. 초안은 현재 브라우저의 localStorage에만 저장하며 서버로 전송하지 않습니다. 정적 파일 호스팅에는 통상적인 호스팅 요청이 발생합니다.

공개 데이터는 이 프로토타입에 필요한 요약으로 정리했습니다. 로컬 경로, 내부 에이전트 경로, 비공개 파일과 원시 대화는 포함하지 않았습니다.

## 실행

빌드나 npm 패키지 설치가 필요 없습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

[로컬 보기](http://127.0.0.1:4173)

GitHub Pages는 main 브랜치의 저장소 루트에서 제공합니다. 모든 자원 경로는 저장소 하위 URL에 대응하는 상대 경로입니다.

## 파일

- index.html / styles.css / app.js: 화면과 브라우저 상호작용
- data/workshops.json: 공개용으로 정리한 두 워크숍 기록
- .nojekyll: 정적 Pages 게시

## 검증 상태

2026-10-18 로컬 Chromium에서 확인했습니다.

- JavaScript 문법 검사, 2개 워크숍·20개 기록·7개 역할 참조 검사 통과
- 데스크톱 1440px: 워크숍 전환, 단계 이동, 자동 재생·정지, 역할·전체 기록 대화상자 확인
- 초안 저장·복원과 HTML 문자열의 비실행, JSON 다운로드 및 내용 확인
- 모바일 390px·태블릿 768px: 가로 넘침 없음, 모바일 대화상자와 키보드 슬라이더 경계 확인
- 로컬 정상 흐름의 브라우저 콘솔 오류·경고 0건
- 공개 파일의 로컬·내부 에이전트 경로 및 알려진 키 형식 검사 통과

현재는 기록 재생의 사용성을 살펴보는 프로토타입입니다. 사람의 수요나 새 AI 실행 품질은 검증하지 않았습니다.
